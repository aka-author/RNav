API
PrintDoc(FileName,PrintSettings)
المُعطىالوصف
FileNameيحدد المسار الكامل، بما في ذلك اسم الملف، للمستند الذي ترغب في طباعته.
PrintSettings
يمثل مصفوفة مفصولة بفواصل تتضمن الإعدادات التالية:
  • اسم الطابعة (PrinterName)
  • عدد النسخ (NumberOfCopies)
  • اتجاه الصفحة (PageOrientation)
  • التحجيم (Scaling)
