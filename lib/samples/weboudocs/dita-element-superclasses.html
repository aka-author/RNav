DITA Element Superclasses

While the DITA specification defines a set of class tokens for each element, we further group elements into broader categories called superclasses. These superclasses are assigned based on the typical behavior and rendering expectations of elements in publication output.

The distinction between block and inline elements is especially important. These two categories affect how content flows and is displayed on the page.

Inline elements represent short text fragments that follow the natural flow of text—left-to-right or right-to-left—and wrap over line breaks as needed. Examples include ph and codeph.

Block elements are typically displayed from top to bottom and span the full width of a page or column. Each block element begins on a new line and may contain other block or inline elements. Examples include p and section.

In the DITAToo Web Output Plug-In, we introduce superclasses to provide extended semantic information for formatting purposes. The XATOOL library is responsible for detecting and assigning superclasses to DITA elements during the HTML generation phase.

Some elements are assigned more than one superclass. In these cases, the first superclass describes how the element behaves in relation to its siblings—whether it occupies block space or flows inline. The second superclass, if present, describes how the element structures its children. For example, the ul element has the superclasses block list, meaning it behaves as a block among its siblings and as a list container for its children.

Table 2.

DITA Element Superclasses
Superclass Description
inline Elements that participate in the inline text flow, wrapping naturally within paragraphs or other block elements.
block Standalone elements that begin on a new line and extend across the page or container width.
block list Block-level elements that contain list structures, such as unordered or ordered lists.
block table Block-level elements that represent tables, such as table or simpletable.
listitem Elements that represent individual items within a list structure.
table Elements that function as containers for tabular content.
table__component Structural components inside tables, such as headers, footers, rows, and cells.
table_entry Table cells (entries) that contain the actual data within a row.
table_row Table rows that contain a set of entry elements.
topic__component Major sections of a topic structure, such as title, body, or shortdesc.
struct_node Root-level DITA structures such as topic and map.
generic Fallback category used when an element does not clearly belong to a more specific superclass.
