Assigning CSS Classes to Output Elements

Purpose

The htmlClassAttr mode assigns a class attribute to the resulting HTML element. It combines various class sources to ensure consistent styling. This mode is typically used as part of the htmlAttrs processing.

Placement

This functionality is implemented in the following stylesheet:

common/publish/matter/htmlattrs.xsl

Features

The htmlClassAttr mode composes the class attribute value based on the following sources:

  • Superclasses—assigned by the DITAToo Web Output Plug-in
  • DITA specification-based classes—transformed by replacing / with __
  • Parsable outputclass—if it includes class='...', the value is appended to the default CSS classes
  • Unparsable outputclass—the entire attribute value is treated as a CSS class name and appended
  • Directly provided CSS class names

Synopsis

Mode: htmlClassAttr.

Parameter Type Meaning
directCSSClassNames xs:string Provides a complete override for the CSS class assignment. When this parameter is used, no other class sources are included in the output—superclasses, DITA classes, and outputclass values are ignored.
insertCSSClassNames xs:string Appended to class names derived from superclasses, DITA classes, and the outputclass attribute.

Using both parameters together does not make sense.

Usage

This mode is automatically invoked within htmlAttrs. However, it can also be applied explicitly in a custom template.

Example: Direct CSS Class Assignment

<xsl:apply-templates select="." mode="htmlClassAttr">
   <xsl:with-param name="directCSSClassNames" select="loc:computeMyCustomCSSClasses(.)"/>
</xsl:apply-templates>

Example: Inserting Additional Class Names

<xsl:apply-templates select="." mode="htmlClassAttr">
    <xsl:with-param name="insertCSSClassNames" select="'funny'"/>
</xsl:apply-templates>

Example: Using outputclass with class attribute

<note outputclass="id='licensing_issues' class='legal_notice'">...</note>

Example: Using outputclass as simple class value

<note outputclass="flagged important">...</note>

Modifying Default Behavior

To override the default class behavior, define a new template with the htmlClassAttr mode in your customization for specific DITA elements.
