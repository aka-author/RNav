Passing Build Properties in the Plug-In

Purpose

Build properties control various aspects of the output generation process. In the DITAToo Web Output Plug-In, property values can be defined at several levels to support flexible configuration and override behavior.

Configuration Levels

The following table lists the supported configuration levels and the corresponding file locations where build properties can be defined.

Level Property File Location
Plug-in configuration cfg/build.properties
Base layout configuration layouts/<base-layout>/<version>/cfg/build.properties
Customization <your-customization>/cfg/build.properties
Certain build Property file path passed to DITA OT using the --propertyfile key

Refer to the DITA Open Toolkit documentation for details on the --propertyfile command-line option.

Property Precedence

In general, properties defined at a higher level override those defined at a lower level. However, this behavior may depend on the specific property and how it is consumed in the transformation process.
