Introduction

The DITAToo Web Output Plug-in is a powerful plug-in for the DITA Open Toolkit that enables content teams to publish DITA-based documents in web help format.

The plug-in is highly customizable and flexible. It allows users to define the visual layout and behavior of output documents using the APIs and extension points it provides.

Beyond web help, the plug-in can be configured to produce a wide range of text-based output formats, including JSON, Markdown, or FictionBook. This versatility makes it a suitable choice for many use cases.

Typical use cases include:

  • Creating highly interactive, responsive web help systems
  • Publishing documentation in specialized formats, such as formats used by onboard vehicle systems
  • Migrating content from DITA to other formats, such as Markdown or ATA 2300
  • Integrating DITA-based workflows with wiki-based platforms or content delivery systems

Web publications generated with the plug-in can also be integrated with systems for collecting reader feedback and measuring user engagement.
