Default CSS Classes

By default, the plug-in assigns the following CSS classes to each HTML element in the output:

  • Superclass or a couple of superclasses—represents the layout behavior of the element
  • DITA classes—derived from the original DITA @class attribute

The superclass class name corresponds exactly to the superclass assigned to the element during classification.

DITA classes are transformed from the original token format by replacing each slash / with double underscore __.

For example, a <cmd> element is converted to the following HTML:

<span class="inline topic__ph task__cmd">...</span>.
