Creating a New Customization

A customization allows you to adjust the structure, visual layout, or behavior of output documents without modifying the original base layout.

  1. Selecting a base layout.

    Identify which base layout matches the type of output documents you want to customize. Each base layout defines a default structure and behavior for a specific output format.

  2. Choosing a name for your customization.

    Choose a unique name for your customized layout. This name will be used to create a folder for the customization and distinguish it from other layouts.

  3. Opening the base layout folder.

    Navigate to the folder of the selected base layout. This folder contains the structure, resources, and scripts required to create a customization.

  4. Running the customization script.

    Execute the customize.bat (on Windows) or customize.sh (on Unix-like systems). Provide the path to the folder where your customization will be created. The script will copy the necessary template files and structure into the target folder.

  5. Modifying customization files.

    Edit or create the relevant files inside your customization folder. You can override styles, templates, configuration files, and other layout components as needed.

  6. Testing and debugging.

    Generate output documents using your new customization. Review the results and fix any issues or incorrect behavior.

  7. Removing unused files.

    Delete any copied files and folders that were not modified. This keeps the customization minimal and easier to maintain.

After completing these steps, your customization will be ready for use in production publishing workflows.
