Build Property Reference

Plug-In

Placement

cfg/build.properties

Properties
Property Value Mode Meaning
defaultLayout A pair of base layout name and version Mandatory A base layout to be applied if customization.dir is not defined
defaultImageFileTypes A whitespace-separated list Can be overridden in a customization File types that will be treated as images during processing

Example

defaultLayout=classtatic 1.01a
defaultImageFileTypes=apng avif bmp gif ico jpg jpeg png svg webp

Base Layout

Placement

layouts/<base-layout>/<version>/cfg/build.properties

Properties
Property Value Mode Meaning
isBaseLayout Any non-empty value Mandatory for a base layout Marks the layout as a base layout
baseLayout A pair of name and version Mandatory Base layout this layout is based on (can point to itself)
requires_js_libs Any non-empty value Optional Indicates that the layout requires copying JavaScript files to the output folder

Example

isBaseLayout=yes
baseLayout=classtatic 1.01a
requires_js_libs=set

Customization

Placement

<your-customization>/cfg/build.properties

Properties
Property Value Mode Meaning
baseLayout A pair of base layout name and version Mandatory Defines the base layout for the customization
requires_js_libs Any non-empty value Optional Indicates that JavaScript files must be copied to the output folder

Example

baseLayout=rawdump 1.01a
requires_js_libs=set

Build

You can specify build-specific properties when invoking the DITA Open Toolkit using the --propertyfile parameter. This lets you define properties in a standalone file for a particular publishing run. Build-level properties may include settings such as the path to the customization directory, a temporary folder location, or specific output configuration switches.

These properties are applied on top of those defined in the plug-in, base layout, and customization levels. In general, properties defined at the build level take precedence, but this is not guaranteed for all properties and depends on how the plug-in implements them.

Example

customization.dir=c:\\techwriting\\tools\\corporate-layout
dita.temp.dir=c:\\tmp\\!ditatoo_weboutput_tmp
clean.temp=no
taxonomy.file=C:\\techwriting\\cookbook\\taxonomy.ditamap
