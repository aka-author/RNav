Assigning Taxonomy to Topics

To associate a DITA topic with taxonomy categories, specify the category codes in one or more othermeta elements with the attribute name set to taxonomy.

The content attribute of the othermeta element contains one or more category codes separated by spaces. The distribution of codes across multiple elements does not affect the outcome—only the resulting set of codes matters.

The example below shows three category codes assigned to a topic. All of them are treated as taxonomy filters during search and classification, regardless of how they are grouped. 

<othermeta name="taxonomy" content="simple dinner"/>
<othermeta name="taxonomy" content="guests"/>

The topic above is associated with the following categories:

  • simple—complexity level
  • dinner—type of meal
  • guests—usage situation
