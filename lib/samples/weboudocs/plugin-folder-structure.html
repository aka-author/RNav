Plug-in Folder Structure

Root Level

Path Description
build.xml The main build file
build_template.xml The template of the main build file

cfg/

Plug-in configuration files.

Path Description
cfg/build.properties General build properties, including the default base layout
cfg/catalog.xml The main XML catalog

doc/

The plug-in's user documentation.

i18n/

Default localization files, including captions for figures, tables, etc.

Path Description
i18n/search/ Resources for search features in web helps, including stopword lists

layouts/

Base layouts included in the plug-in.

Path Description
layouts/classtatic/ A base layout for classical static web helps
layouts/rawdump/ A base layout for draft one-pagers

lib/

Libraries used by the plug-in, layouts, customizations, and output documents.

Path Description
lib/kwish/ JavaScript library enabling web help responsiveness, user interface, and search
lib/xatool/ XSLT library for assembling blocks of output documents

publish/

The main set of XSLT stylesheets of the plug-in.

samples/

Sample DITA projects and output documents.
