Styling Topic Matter

The appearance of topic content is defined in the file yourLayout/front/css/matter.css. This file contains styles for paragraphs, lists, tables, inline elements, and other structural components of a topic.

1.
Open the file yourLayout/front/css/matter.css in your code editor.
2.
Edit or add the necessary CSS rules to adjust the appearance of topic content.
3.
Save the file matter.css.
