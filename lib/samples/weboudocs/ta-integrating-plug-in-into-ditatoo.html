Integrating the Plug-In into a DITAToo Instance

The following prerequisite is mandatory for deploying the plug-in on your computer.

  • The plug-in is integrated into your instance of DITA OT.
1.
Launch DITAToo Author.
2.
Select the command PublishManage Publishing Targets...

The Manage Publishing Targets form appears.

3.
Click the Add button under the list of targets.

A small form appears.

4.
Fill in the form as shown below.
Form field Value
Name DITATooWeboutput
Transform ditatoo.weboutput
Target dita2ditatoo.weboutput
Extension .html
5.
Click the OK button.
The Manage Publishing Targets form appears again.
6.
Select DITAToo Weboutput in the Publishing Targets list.
7.
Enter the target properties in the Target properties area as shown below.
Table 1.

Target properties
Target Property Value
args.input ${projdir}/${MAP_file}
dita.extname ${EXTNAME}
outer.control quiet
output.dir ${outdir}
8.
Click the OK button.

The plug-in installation is now complete. You can start using the plug-in with DITAToo.
