Sample: Appending a Footer to a Page

This example demonstrates how to append a footer to a page. Page footers will contain a copyright message.

1.
Create a new customization based on the Classtatic base layout.
2.
Enable the local page template.
3.
Edit the file yourLayout/publish/pages/regular-page.xsl. Specifically, append a footer at the bottom of the page.
        <!-- /Konsole keeper -->
        <footer>(c) 2025 Puke Green Walley Corp. All rights reserved.</footer>    
    </div>
    <!-- /Shell -->
</body>
4.
Redefine the related sizes in yourLayout/front/css/helpui.css.
a)
Define the footer height by adding the definition as given below.
/* Footer */
:root {
    --footer_height: 30pt;
}
b)
Decrease the console height by the footer height.
/* Consoles */
:root {
    --console_width: 100vw;
    --console_height: calc(100vh 
        - var(--page_header_height) 
        - var(--minimal_indent) 
        - var(--footer_height));
}
5.
Assign style properties to page footers.
footer {
    height: var(--footer_height);
    background: var(--gray700);
    color: #ffffff;
}

A footer appears at the bottom of each page.
