Changing the Page Structure

In the plug-in, the structure of HTML pages is defined in page templates. The base layout Classtatic uses a single page template that defines the structure of every regular page in a web help system. By default, a customization uses the original template stored in the base layout's folder. To modify the structure, the customization must activate a local copy of the template stored in its own folder and apply the required changes there.

1.
Open the yourLayout/publish/custom.xsl in your code editor.
2.
Uncomment line <xsl:import href="pages/regular-page.xsl"/>.
3.
Save the file custom.xsl.
4.
Open the yourLayout/publish/pages/regular-page.xsl file in your code editor.
5.
Change the page structure based on comments and you knowledge of the HTML.
6.
Save the regular-page.xsl file.
<?xml version='1.0'?>
<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform" version="2.0"
    xmlns:loc="http://itsurim.com/local" xmlns:xat="http://itsurim.com/xatool"
    exclude-result-prefixes="loc xat">

    <xsl:import href="cfg:baselayout.xsl"/>
    <xsl:import href="pages/regular-page.xsl"/>

     <!-- ... -->

</xsl:stylesheet>
