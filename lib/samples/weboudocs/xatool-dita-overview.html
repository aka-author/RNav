Overview

Purpose

This block defines a set of reusable functions and templates for inspecting and categorizing DITA elements. It supports the implementation of higher-level logic by exposing reliable queries about element properties and classification.

Features

  • Superclass Detection — identifies formatting-oriented categories such as block, inline, list, table, and structural nodes
  • Mixed Content Normalization — separates inline nodes from blocks and removes unnecessary containers in mixed-content elements
  • Element Queries — retrieves element IDs, languages, topic depth, titles, metadata, and DITA class membership

Usage

To enable all features of this block, import the following stylesheet:

lib/xatool/dita/xsl-2.0/dita.xsl
