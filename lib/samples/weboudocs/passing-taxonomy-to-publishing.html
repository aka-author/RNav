Passing a Taxonomy to the Publishing Process

To enable taxonomy-based features in the DITAToo Web Output Plug-in, you should pass your taxonomy to the publishing process. This is done by defining a publishing property named taxonomy.file.

The value of the taxonomy.file property is the path to your subject scheme map file. The path format must match the syntax required by your operating system.

Note
On Windows, use double backslashes (\\) instead of single backslashes (\) in file paths. This is required because the backslash is an escape character in Java property files.

Where and how you define the taxonomy.file property depends on the tool you use to run DITA OT:

  • Command line: Create or edit a .properties file and define the property in that file. Then run DITA OT with the --propertyfile=yourfile.properties argument.

  • CMS or authoring tool: If your content management system, editor, or publishing environment allows custom properties to be passed to DITA OT, define taxonomy.file using its configuration interface or publishing settings.

The sample below shows a typical .properties file used when publishing from the command line on Windows. 

dita.temp.dir=C:\\tmp\\ditaot
dita.extname=.html
taxonomy.file=C:\\techwriting\\cookbook\\taxonomy.ditamap

This configuration ensures that the taxonomy map located at the specified path is processed during output generation. The plug-in uses the taxonomy to enable features such as faceted search or category filtering in supported layouts.

For additional configuration guidance, refer to the documentation for your version of DITA OT or your CMS’s publishing documentation.
