Assigning Attributes from Outputclass

Purpose

This mode assigns additional attributes to the resulting HTML element based on the parsed value of the outputclass attribute. This behavior allows authors to inject arbitrary HTML attributes using DITA source markup.

Placement

This functionality is implemented in the following stylesheet:

common/publish/matter/htmlattrs.xsl

Features

Attributes are extracted from a outputclass value if it follows the syntax of an HTML attribute snippet. This feature enables setting arbitrary HTML attributes on output elements without modifying stylesheets.

The following constraints apply:

  • Both single quotes (') and double quotes (") are supported.
  • All attribute values in a single outputclass string must use the same type of quotation marks. Mixing is not allowed.
  • The id and class attributes are ignored by this mode. These are handled by htmlIdAttr and htmlClassAttr.

Synopsis

Mode: htmlAttrsFromOutputclass.

Usage

This mode is used internally by htmlAttrs. You typically do not need to apply it directly. However, it can be used in a custom template when constructing an element manually.

Example: Defining attributes using outputclass

<fig outputclass="data-kwish-control='DrawingViewer'">...</fig>

Produces:

<figure data-kwish-control="DrawingViewer">...</figure>

Modifying Default Behavior

Modifying the default behavior is strongly not recommended.
