Using Local XSLT API

Purpose

The Local XSLT API is part of the DITAToo Web Output Plug-in. It defines functions and templates used for built-in formatting and structural processing in the output. The API also provides an interface for extending and customizing layout behavior.

Placement

The Local XSLT API modules are located in the publish subfolder of the plug-in folder.

Features

  • Default processing and formatting built into the plug-in
  • Support for custom layout development via reusable templates and fumctions

Usage

The namespace declaration for calling local functions is:

xmlns:loc="http://itsurim.com/local"

The Local XSLT API becomes available in your own stylesheet once you import the base layout module:

<xsl:import href="cfg:baselayout.xsl"/>

This import triggers the following effects:

  • The customization inherits default transformations from DITA to HTML
  • XATool functions and templates become available to the customization
