Assigning Full Set of Attributes

Purpose

The htmlAttrs mode assigns the complete set of standard attributes—id, class, and any additional attributes defined in a parsable outputclass—to an output HTML element. This mode centralizes the logic for assigning HTML attributes during transformation.

Placement

This mode is implemented in the following stylesheet:

common/publish/matter/htmlattrs.xsl

Features

The htmlAttrs mode performs the following tasks:

  • Assigns an id attribute using the htmlIdAttr mode
  • Assigns a class attribute using the htmlClassAttr mode
  • Assigns additional HTML attributes defined in a parsable outputclass using the htmlAttrsFromOutputclass mode

Synopsis

Mode: htmlAttrs.

Parameter Type Meaning
directId xs:string Assigns a fixed ID to the element, overriding all other sources.
directCSSClassNames xs:string Specifies a fixed list of CSS class names and disables all other sources.
insertCSSClassNames xs:string Appends additional CSS class names to those derived from superclass, DITA class, and outputclass.

Use directCSSClassNames and insertCSSClassNames for different purposes. Do not use them together.

Usage

The plug-in applies this mode automatically when generating output HTML elements. You typically do not need to invoke it manually unless overriding default behavior in a custom template.

Example

<xsl:template match="note[@type='danger']">
   <div>
      <xsl:apply-templates select="." mode="htmlAttrs">
         <xsl:with-param name="insertCSSClassNames" select="'alert-danger'"/>
      </xsl:apply-templates>
       <!-- custom content -->
   </div>
</xsl:template>

Modifying Default Behavior

You can redefine a template in the htmlAttrs mode for specific DITA elements to customize how HTML attributes are generated during transformation.
