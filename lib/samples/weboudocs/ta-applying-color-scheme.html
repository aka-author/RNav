Applying a Color Scheme

A color scheme is a coordinated group of CSS variables that define the visual tone of output documents. It is not recommended to assign arbitrary colors to individual elements. Instead, update the values of centralized CSS variables to ensure consistent appearance across the interface.

The default scheme defines primary colors for interactive elements using the following variables:

  • --control_primary
  • --control_hover
  • --control_active
  • --control_disabled

These variables should belong to the same tone (for example, all blue, all green, or all orange). Do not mix unrelated tones. For example, assigning green to --control_primary and red to --control_hover leads to inconsistent styling.

Do not redefine grayscale colors such as --gray500 or --gray100 unless you fully understand the visual impact. These variables are used broadly for layout backgrounds, borders, and text contrast.

If you are not a trained graphic designer, following these constraints is the safest way to prevent output documents from appearing unbalanced or unprofessional. If you are, you may redefine or expand the color scheme as needed.

The color scheme is defined in the CSS file yourLayout/front/css/helpui.css, near the top, in the section marked with the comment /* Color scheme */.

1.
Open the file yourLayout/front/css/helpui.css in your code editor.
2.
Locate the section marked with the comment /* Color scheme */.
3.
Change the color values of variables such as --control_primary, --control_hover, --control_active, and --control_disabled.
4.
Save the file helpui.css.
/* Color scheme */

:root {
    --control_primary:   #0180c3;
    --control_hover:     #1da6ff;
    --control_disabled:  #e8f3fe;
    --control_active:    #0973dd;
    --control_stressed:  #950606;
    --dark:     #202225;
    --gray700:  #616569;
    --gray480:  #92979d;
    --gray500:  #c2c9d1;
    --gray400:  #e1e4e8;
    --gray300:  #f0f2f3;
    --gray200:  #f9fafa;
    --gray100:  #fcfcfd;
}
