DITA Query Functions

Purpose

This module provides a set of utility templates and functions used throughout the XATOOL pipeline to query properties of DITA elements, such as their identity, structural role, language, nesting level, and metadata. These queries are used in classification, document analysis, formatting, and preprocessing stages.

Placement

This functionality is implemented in the following stylesheet:

lib/xatool/dita/xsl-2.0/guts/queries.xsl

Functions

Each function accepts a DITA element as an argument and returns a boolean value or a string depending on its query purpose.

Function Description
xat:dita.id($element) Returns the value of id if present, otherwise generates a temporary ID using generate-id().
xat:dita.local($element) Extracts the language code (e.g. "en") from the xml:lang attribute or inherits it from the parent.
xat:dita.lang($element) Alias to xat:dita.local(), normalized to the language prefix (e.g. "en" from "en-US").
xat:dita.makeLocalCode($lang, $country) Builds a local code in the format en-US.
xat:dita.makeLocalSuffix($lang, $country) Builds a local suffix in the format en_US.
xat:dita.isTerminalTopic($topic) Returns true if the topic has no nested topics.
xat:dita.isFolderTopic($topic) Returns true if the topic contains other topics.
xat:dita.isStructNode($element) Returns true for maps and topics (structural nodes).
xat:dita.hasDirectContent($topic) Returns true if the topic contains a body element.
xat:dita.level($topic) Returns the nesting level of the topic within its parent topics.
xat:dita.plainTextTitle($element) Returns the normalized text of the element’s title.
xat:dita.plainTextDocTitle($element) Returns the title of the root map or bookmap.
xat:dita.fileUri($element) Returns a resolved file URI based on xtrf, using the xat:path.2uri utility.
xat:dita.othermeta($element, $name) Retrieves the value of a named othermeta from a topic or map.
xat:dita.directOthermeta($element, $name) Returns a directly defined othermeta (not inherited from a map).
xat:dita.hasClass($element, $classList) Checks whether the element’s class contains any of the specified tokens.
