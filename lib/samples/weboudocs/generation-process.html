Document Generation Process

Input Data

The input data consists of the following components:

  • A top-level ditamap file representing the main document

  • Referenced submaps that define the hierarchical structure of the content

  • DITA topic files of various types (concept, task, reference)

  • Image files referenced from topics

  • Other referenced resources, including reusable content and filtering conditions

Output Data

The output data includes the following components:

  • HTML or other text-based files representing the published document

  • JavaScript data files (e.g., table of contents, search indices)

  • Copied and renamed image files used in the content

  • CSS files, JavaScript libraries, and other predefined technical assets

Transformation Stages

The generation process includes the following stages:

  • Linking source files into a unified internal structure.

  • Applying filters to include or exclude content based on provided conditions.

  • Generating content files in the desired output format.

  • Copying and arranging referenced image files.

  • Assembling the final output folder with all necessary assets.

As a result, a ready-to-use output document is created and stored in the output folder.
