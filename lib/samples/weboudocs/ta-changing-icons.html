Changing Icons

The default Classtatic layout uses the icons listed below. The icons are stored in the folder yourLayout/front/img.

Icon File Purpose
burger.svg Accessing to the TOC of the document on narrow screens
burger-unfolded.svg Closing the TOC of the document on narrow screens
close-24px.svg Closing the TOC framelet on wide screens
arrow-right.svg Opening a TOC entry
arrow-down.svg Closing a TOC entry
search.svg Searching topics
close-red.svg Clearing current search criteria and the results of current search
taxonomy.svg Opening or closing a search taxonomy
print.svg Printing the current page
1.
Change each icon in your graphic editor or replace it with another graphic file.
