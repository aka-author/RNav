Changing Page Geometry

The geometry of a web help page is based on a system of interconnected sizes. In many cases, a change to one size requires a corresponding change to another. A dependent size can be equal to, a multiple of, or a fraction of the size being modified.

Sizes must not be arbitrary. Otherwise, pages will look messy and unbalanced. There must be a limited set of distinct sizes that repeat across the page layout, creating a visual rhythm. These sizes should be proportionally related to one another. Without such consistency, the result will be visually chaotic and structurally weak.

To support consistent and maintainable changes, the Classtatic base layout defines a compact system of core size variables. You can control the page geometry by adjusting these core sizes. It is technically possible to assign each individual size directly. In some cases, doing so is justified. However, in general, this approach is discouraged, as it often breaks the internal consistency of the layout.

The sizes which are essential the Classtatic layout are listed below.

Variable Size
--major_indent The distance between the window border and the borders of a framelet. The width of the gap between framelets
--minor_indent

The distance between a framelet border and its content.
--tiny_indent The distance between the border of a group and the icons that belong to it. The distance between icons within the same group
--minimal_indent

The distance needed to prevent adjacent elements from sticking together

--large_icon_size The size of icons such as the burger icon and the print icon
--usual_icon_size The size of icons such as the search icon
--small_icon_size

The size of icons such as the clear search icon and the taxonomy icon

--major_border_radius

The border radius of framelets
--minor_border_radius

The border radius of the block that appears around a selected TOC entry.

--page_header_height The height of the page header
--console_height The height of the area where framelets appear
1.
Open the file yourLayout/front/css/helpui.css in your code editor.
2.
Modify the values of the variables listed in the table above.
3.
Save the file helpui.css.
/* Basic metric parameters */

:root {
    --major_indent: 15pt;
    --minor_indent: calc(var(--major_indent)/2);
    --tiny_indent: calc(var(--major_indent)/3);
    --minimal_indent: 1pt;

    --major_margins: calc(2*var(--major_indent));

    --large_icon_size: 36px;
    --usual_icon_size: 24px;
    --small_icon_size: 16px;

    --major_border_radius: 5pt;
    --minor_border_radius: 2pt;
}
