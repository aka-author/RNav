Usage Scenarios

The DITAToo Web Output Plug-in supports various usage scenarios, allowing teams to adapt it to their existing documentation environments and publishing workflows.

Common usage scenarios include:

  • Standalone use within a DITA Open Toolkit instance, without integration into other systems
  • Integration with Intuillion’s DITAToo DITA CCMS for seamless publishing within a component content management workflow
  • Integration with third-party authoring tools or content systems, enabling custom publishing pipelines or automated outputs
