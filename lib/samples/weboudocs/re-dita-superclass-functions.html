Superclass Detection in DITA Web Output

Purpose

The superclass detection system groups DITA elements into behavioral categories such as block, inline, list, or table component. These categories inform formatting logic in the DITAToo Web Output Plug-In by providing layout hints for CSS-based HTML output.

Placement

This functionality is implemented in the following stylesheet:

lib/xatool/dita/xsl-2.0/guts/classify.xsl

Functions

Table 3.

Superclass Detection Functions
Function Purpose
xat:dita.isInline Returns true() if the element behaves as an inline element.
xat:dita.isBlock Returns true() if the element behaves as a block element.
xat:dita.isList Returns true() if the element is a list container (e.g., ul, ol).
xat:dita.isListItem Returns true() if the element is a list item (e.g., li).
xat:dita.isTable Returns true() if the element is a table container.
xat:dita.isTableComponent Returns true() for rows, headers, footers, and similar table parts.
xat:dita.isTableRow Returns true() if the element is a table row.
xat:dita.isTableEntry Returns true() if the element is a table entry (cell).
xat:dita.isTopic Returns true() if the element is a topic.
xat:dita.isMap Returns true() if the element is a map.
xat:dita.isTopicComponent Returns true() if the element is part of a topic structure (e.g., body, title).
xat:dita.superclass Returns the space-separated string of superclasses assigned to a given element.

Modifying Default Behavior

Each detection function delegates to an internal template using a corresponding mode. For example, the xat:dita.isBlock function applies a template in mode xat.dita.isBlock to the element it receives as an argument.

To change the superclass behavior for a specific element, you can override the default template with a higher-priority template using the same mode. This technique allows you to customize formatting classification without altering the base detection logic.
