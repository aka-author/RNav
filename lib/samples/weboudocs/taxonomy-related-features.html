Taxonomy-Related Features

A taxonomy is a hierarchy of categories that helps organize content meaningfully. In the DITAToo Web Output Plug-in, taxonomies are primarily used to enhance topic search. This allows users to locate topics not only by searching for text but also by filtering topics based on their association with selected categories in the taxonomy.

The way taxonomies are used may differ depending on the specific base layout or customization. Each base layout can implement its own mechanisms for taxonomy usage and display.

This documentation covers the taxonomy-related features implemented in each supported base layout separately. Currently, the following base layout supports taxonomical search:

  • Classtatic
