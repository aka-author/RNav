Classes of DITA Elements

According to the DITA specification, each element must have at least one class. A class identifies the semantic category of the element and indicates its position in the specialization hierarchy.

For example, the li element, which represents a list item, has the class topic/li. An element that is specialized from another element inherits its class and adds its own. For example, the step element, which is specialized from li, has two classes: topic/li and task/step.

Formatting in publication is based on these classes. The processing logic in the DITA Open Toolkit applies output rules by matching class values, not element names.

The DITA Open Toolkit preprocessor assigns the list of classes to the class attribute during preprocessing. A class name consists of the name of the DITA domain or module followed by the element name, separated by a slash. For example, in preprocessed output, the step element appears as follows: 

<step class="- topic/li task/step ">

Here, the class attribute includes both the base class topic/li and the specialized class task/step. The value begins with a dash (-) and ends with a space to enable reliable string matching during processing.
