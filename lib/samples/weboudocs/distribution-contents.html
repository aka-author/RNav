Distribution Contents

The distribution archive includes all components required to install and evaluate the DITAToo Web Output Plug-in. It contains the core software, base layouts, and supporting materials for hands-on use and initial configuration.

Main software components:

  • Core of the DITAToo Web Output Plug-in.

Base layouts:

  • Calsstatic—Generates classical web help consisting of static HTML pages. Each help page is split into two panes: the left pane displays the document TOC with collapsible and expandable sections, while the right pane displays the topic content. The layout supports both full-text search and taxonomy-based filtering.

  • Rawdump—Transforms the source document into a single long HTML page that includes all topics arranged sequentially. This layout is suitable for quick linear reading or printing.

Learning materials:

  • User Manual
  • Sample projects

The materials are supplied as a single ZIP archive. To start using the solution, unzip the archive and follow the instructions in the User Manual.
