Defining a Logo Image

1.
Copy your logo image file to yourLayout/front/img.
2.
Open the file yourLayout/front/css/helpui.css in your code editor.
3.
Assign your logo filename as a value to the property --background-image of the #logo element.
4.
Measure the ratio: logo width divided by logo height.
5.
Assign the ratio as a value to the variable --logo_image_width_to_height_ratio.
6.
Save the file helpui.css.
:root {
    
    /* Measure the actual w/h of your logo! */
    --logo_image_width_to_height_ratio: 2.54; 

    --logo_height: var(--page_header_height);
    --logo_width: calc(var(--logo_height)*var(--logo_image_width_to_height_ratio));
    --logo_image_top_margin: var(--minimal_indent);
    --logo_image_height: calc(var(--logo_height) - 2*var(--logo_image_top_margin));
    --logo_area_width: calc(var(--logo_width) + var(--major_indent));
}

#logo {
    display: inline-block;
    width: var(--logo_width);
    height: var(--logo_height);
    margin-inline-start: var(--major_indent);
    background-image: url('../img/your-logo.svg');
    background-size: var(--logo_width) var(--logo_height);	
}
