Describing a Taxonomy

In the DITAToo Web Output Plug-in, taxonomies are described using subject scheme maps in accordance with the DITA specification. A taxonomy defines a hierarchy of categories that can be used to classify topics and support taxonomy-based search in output documents.

The root element representing a taxonomy is subjectScheme. Each category in the taxonomy is defined using a subjectdef element nested within it or within another category.

Each subjectdef must have a navtitle attribute, which provides the human-readable name of the category.

If the category is intended to be assigned to a topic or appear as a search criterion, the subjectdef must also include a keys attribute. The value of the keys attribute serves as the category's internal code.

Both terminal categories and grouping categories (those that contain subcategories) can be assigned to topics and used for search filtering.

A subjectdef element that has a navtitle but does not include a keys attribute is treated as a facet. Facets serve as grouping containers and cannot be directly assigned to topics.

The following example shows how to define a taxonomy using a subject scheme map.

<subjectScheme>
   <subjectdef keys="taxonomy">
      <!-- Type of Meal (a facet) -->
      <subjectdef navtitle="Type of Meal">
            <subjectdef keys="breakfast" navtitle="Breakfast"/>
            <subjectdef keys="lunch" navtitle="Lunch"/>
            <subjectdef keys="dinner" navtitle="Dinner"/>
            <subjectdef keys="supper" navtitle="Supper"/>
      </subjectdef>
      <!-- Situation (a facet) -->
      <subjectdef navtitle="Situation">
         <subjectdef keys="ceremonial" navtitle="Ceremonial">
            <subjectdef keys="festive" navtitle="Festive"/>
            <subjectdef keys="somber" navtitle="Somber"/>
         </subjectdef>
         <subjectdef keys="everyday" navtitle="Everyday">
            <subjectdef keys="family" navtitle="Family"/>
            <subjectdef keys="guests" navtitle="Guests"/>
         </subjectdef>
         <subjectdef keys="fast" navtitle="Fast">
            <subjectdef keys="eat_in" navtitle="Eat in"/>
            <subjectdef keys="take_away" navtitle="Take away"/>
         </subjectdef>
      </subjectdef>
      <!-- Complexity (a facet) -->
      <subjectdef navtitle="Complexity">
         <subjectdef keys="complex" navtitle="Complex"/>
         <subjectdef keys="medium" navtitle="Medium"/>
         <subjectdef keys="simple" navtitle="Simple"/>
      </subjectdef>
   </subjectdef>
</subjectScheme>
